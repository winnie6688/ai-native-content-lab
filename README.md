# AI Native Content Lab

AI 原生内容实验室是围绕「AI 原生进化论」搭建的内容生产 Skill 系统。

当前 V1 先聚焦微信公众号内容生产，目标是把账号定位、品牌风格、排版规范、封面提示词、事实校验和发布前检查沉淀为可复用的 ChatGPT Skills。
