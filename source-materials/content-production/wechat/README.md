# WeChat Source Materials

This folder stores source materials for the WeChat Official Account content production system.

## Current source materials

- `one-page-wechat.md`: the master one-page document for the WeChat Official Account 「要AI不释手」, including account positioning, column system, brand colors, writing rules, GEO rules, visual rules, layout template, and publication checklist.

## Relationship with skill-library

`ai-native-content-lab` is the source project for content production assets.

`skill-library` extracts reusable Skills from these source materials.

When the WeChat one-page document changes, update this repository first, then update related Skills in `skill-library` if needed.
