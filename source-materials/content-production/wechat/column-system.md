## 一级栏目说明

### 1. 《AI 协作实验》

这是账号的主栏目，记录我如何和 AI 一起做事，把想法、问题、工具和概念转化为真实可用的方法、流程和小系统。

核心作用：AI 协作 / 实践探索 / 方法沉淀。

主要内容方向：记录和 AI 一起做产品、做提效、拆问题、补基础，搭建工作流的真实过程。

#### 二级栏目：造物笔记

每一次探索，都是一个想法被认真对待后的结果。它不一定宏大，但真实解决了一个问题。

栏目定位：想法落地 / 从 0 到 1。

主要内容方向：AI Coding、小系统开发、后端服务、Skill、自动化流程、内容系统等项目复盘。

#### 二级栏目：从卡点到解法

卡住并不可怕，真正重要的是：能不能把问题拆开，找到继续往前走的路径。

栏目定位：问题拆解 / 解法沉淀。

主要内容方向：API、鉴权、安全、部署、数据库、对象存储、提示词、AI Coding 等具体卡点与解决方案。

#### 二级栏目：工具炼金术

工具的价值，不在于拥有多少，而在于能不能被组合成真正顺手的工作方式。

栏目定位：工具整合 / 效率提升。

主要内容方向：ChatGPT、Coze、飞书、GitHub、TRAE、剪映、即梦、浏览器、知识库等工具组合实践。

#### 二级栏目：概念补给站

概念不是为了背诵，而是为了让我在真正做事时，知道自己正在操作什么、为什么这样做、下一步该怎么判断。

栏目定位：基础认知 / 概念解释 / 学习补给。

主要内容方向：Skill、CLI、部署、API、数据库、对象存储、环境变量、Token、JWT、前端、后端、云服务等基础概念讲解。

### 2. 《边走边想》

固定结束语：路还很长。但我们已经在路上。

栏目简介：记录成长过程中的思考、复盘与自我修正。

核心作用：个人成长 / 思考记录。

主要内容方向：记录成长过程中的认知变化、情绪复盘、职业思考和长期主义。

### 3. 《书籍推荐》

固定结束语：好的书籍不会立刻改变人生，但会慢慢改变你看世界的方式。

栏目简介：分享真正启发过我的书，以及它们如何影响我看世界、看自己、看问题。

核心作用：阅读输入 / 认知补给。

主要内容方向：分享真正启发过我的书，以及它们如何改变我看问题的方式。

### 4. 《热钱之外》

固定结束语：市场每天都很热闹，但真正值得长期依靠的，不是消息，也不是运气，而是逐渐成熟的判断力。如果你也想从追热点，慢慢走向理性投资，欢迎一起学习、观察和复盘。

栏目简介：写给普通投资者的理性投资观察栏目，陪你从追热点慢慢走向理性投资。

核心作用：投资理性 / 市场观察。

主要内容方向：用金融机构视角和个人投资经验，陪普通投资者理解市场、风险、收益和自己。

### 5. 《AI 简报》

固定结束语：AI 的变化很快，但重要的不是知道每一条消息，而是从这些变化里看见趋势、边界和机会。这份简报不追逐热点，也不堆积资讯，只希望陪你在持续观察中，慢慢建立属于自己的判断力。

栏目简介：记录国内外 AI 商业、监管、投资、产品和技术动态，帮助读者从快速变化的信息中识别趋势、边界与机会。

核心作用：AI 资讯整理 / 趋势观察 / 机会识别。

主要内容方向：追踪国内外 AI 大厂、Agent 技术、政策监管、一级/二级市场投资动态、劳动力市场影响，并提炼对产品、企业和个人的启发。
