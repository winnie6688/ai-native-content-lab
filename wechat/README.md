# WeChat Official Account Skill Group

This folder contains the WeChat Official Account Skill group for AI Native Content Lab.

## V1-alpha Skill list

- `wechat-brand-context`: platform-specific brand context master source
- `wechat-content-polisher`: article polishing and structure improvement
- `wechat-title-generator`: WeChat title generation and optimization
- `wechat-html-css-layout`: HTML/CSS layout generation based on brand style
- `wechat-cover-generator`: cover image prompt and structure generation
- `wechat-geo-summary`: 120-character GEO-friendly summary generation
- `wechat-fact-checker`: technical and factual accuracy checking
- `wechat-publish-checker`: final pre-publication checklist and review

## Design principle

Each Skill should be independently callable. The creator manually chooses which Skill to use according to the article's current stage.
