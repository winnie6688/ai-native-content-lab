# WeChat Skills

This directory stores the WeChat content-production Skill group mirrored inside `ai-native-content-lab`.

## Relationship with repositories

`ai-native-content-lab` is the content production project and should keep a local mirror of the WeChat Skill group so the project can evolve together with its source materials.

`skill-library` remains the dedicated Skill source library and packaging / distribution repository.

## Current WeChat Skill group

- `wechat-brand-context`: brand positioning, tags, column system, voice, and visual rules.
- `wechat-content-polisher`: polish and restructure WeChat drafts while preserving sincere practice-based voice.
- `wechat-title-generator`: generate clear, searchable, restrained titles.
- `wechat-html-css-layout`: generate WeChat-compatible HTML/CSS using the official brand color system.
- `wechat-cover-generator`: generate cover concepts and prompts aligned with the brand.
- `wechat-geo-summary`: generate AI-search-friendly summaries, keywords, and long-tail questions.
- `wechat-fact-checker`: verify technical, financial, regulatory, and current AI claims.
- `wechat-publish-checker`: final publication checklist.

## Latest strategic state

Unchanged:

- GEO / AI-Friendly Writing remains the long-term content strategy.
- Brand color system remains unchanged.
- Article structure remains unchanged.
- Sincere, restrained, non-hype voice remains unchanged.

Changed:

- Account positioning has shifted from “AI Coding product implementation” to “non-technical knowledge worker AI collaboration practice”.
- The main column has shifted from 《AI 产品落地指南》 to 《AI 协作实验》.
- 《AI 协作实验》 now includes four sub-columns: 造物笔记, 从卡点到解法, 工具炼金术, 概念补给站.
