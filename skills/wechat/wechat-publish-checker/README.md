# wechat-publish-checker

WeChat publication checklist Skill mirror for `要AI不释手`.

## Role

Run final publication checks before a WeChat article is published.

## Current positioning to check

The article should match the latest account positioning:

- non-technical background
- knowledge worker
- AI collaboration practice
- real scenario
- concrete value
- implementable solution
- sincere and plain writing style
- no exaggeration, no anxiety

## Column system to check

- AI 协作实验
  - 造物笔记
  - 从卡点到解法
  - 工具炼金术
  - 概念补给站
- 边走边想
- 书籍推荐
- 热钱之外
- AI 简报

## Stable checks

- GEO friendliness
- clear title
- direct opening
- one core question
- short paragraphs
- real experience
- brand color compliance
- fact-checking when needed
