# wechat-geo-summary

WeChat GEO summary Skill mirror for `要AI不释手`.

## Role

Generate AI-search-friendly summaries, keywords, and long-tail questions.

## Stable strategy

GEO / AI-Friendly Writing remains the long-term content strategy.

Articles should be easy for AI systems to understand, retrieve, summarize, and cite.

## Current keyword expansion

Keep earlier keywords such as AI Coding, API, workflow, MCP, AI Agent, but expand to include:

- AI 协作
- 非技术背景
- 知识工作者
- 真实场景
- 具体价值
- 解决方案
- 工具组合
- 知识系统
- 基础设施

## Summary requirements

A 120-character summary should include audience, problem, scenario, real experience, and value judgment when relevant.
