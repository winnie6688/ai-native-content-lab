# wechat-title-generator

WeChat title generation Skill mirror for `要AI不释手`.

## Role

Generate clear, searchable, restrained WeChat titles.

## Current positioning to follow

The account is no longer only about AI Coding product implementation. It now focuses on non-technical knowledge worker AI collaboration practice.

Titles should emphasize:

- reader identity
- real scenario
- concrete problem
- value judgment
- solution path
- AI-search friendliness

## Avoid

- title-bait
- anxiety-driven titles
- exaggerated AI promises
- pure tool worship without scenario and value
