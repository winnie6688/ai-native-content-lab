# Color System

Canonical brand colors for 「要AI不释手」.

| Role | Hex | Name | Usage |
|---|---:|---|---|
| Primary brand | `#8DAA91` | Sage Green | Titles, emphasis, module titles, brand identity |
| Secondary brand | `#C2A878` | Linen Brown | Editor notes, warmth, soft background accents |
| Body text | `#2F3437` | Graphite Black | Long-form body text |
| Secondary text | `#666666` | Warm Gray | Secondary explanation |
| Annotation text | `#6B6B6B` | Mist Gray | Reading time, notes, sources |
| Page background | `#F7F6F3` | Ivory Beige | Overall page background |
| Light module background | `#EEF1EC` | Soft Moss Gray | Normal cards |
| Divider | `#DDE2DA` | Silver Sage | Borders and dividers |
| Weak emphasis background | `#E7ECE6` | Cloud Sage | Quote/core idea modules |
| Method module background | `#F3F5F1` | Cedar White | Methods, steps, checklists |
| Highlight text | `#66786B` | Forest Sage | Small-scale emphasis |

Avoid old gray-purple palettes, high-saturation blue-purple, neon colors, and excessive gradients.
