# Project Overview

## Project name

AI Native Content Lab / AI 原生内容实验室

## Goal

Build a modular ChatGPT Skill system for content production across platforms.

The first version focuses on WeChat Official Account publishing. The system will help transform drafts, notes, and project reflections into polished, brand-consistent, technically accurate, and publication-ready content assets.

## Core principles

1. Platform-specific Skill groups instead of a single universal content Skill.
2. Manual orchestration by the creator instead of rigid workflow automation.
3. Each Skill should be independently callable and have clear boundaries.
4. Brand context should be maintained as a master source and copied into relevant platform-specific Skill references.
5. Technical and factual accuracy should be checked before publication.

## First platform

WeChat Official Account.
